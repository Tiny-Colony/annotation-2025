# annotation-2025

このリポジトリは，テキストの「解釈（意味の言い換え・要約）」を **人手** と **LLM出力** で比較できるデータを公開するためのものです．  
公開データは **個人情報（PII）を除去済み** の前提で提供しています．
補足: 元データはExcelから変換して作成しています．

| カラム名 | 説明 |
|---|---|
| `解釈対象テキスト` | 解釈（言い換え・要約等）の対象となる原文テキスト |
| `実験者１` | 人手（実験者1）による解釈 |
| `実験者２` | 人手（実験者2）による解釈 |
| `実験者３` | 人手（実験者3）による解釈 |
| `レビュー済み正解データ` | レビュー後に確定した参照（正解）データ |
| `メモ` | 補足メモ（任意） |
| `辞書判定` | 辞書ベース等での判定結果（任意） |
| `Ollama-GPT-OSS-120B(単文)` | LLM出力（120B / 単文入力） |
| `Ollama-GPT-OSS-120B(+前後40発話)` | LLM出力（120B / 前後コンテキスト付き） |
| `Ollama-GPT-OSS-20B(単文)` | LLM出力（20B / 単文入力） |
| `Ollama-GPT-OSS-20B(+前後40発話)` | LLM出力（20B / 前後コンテキスト付き） |
